# Scan-of-the-week rotation queue.
#
# Process: see docs/scan-of-the-week.md (runbook). The scan session is
# network-restricted, so the target is PRE-CLONED and nox scans a local
# path fully offline (--offline) — no egress-policy change needed (#136).
#
# Bi-weekly cadence, alphabetical-first selection. The /schedule
# job pops the top non-comment line, runs `nox scan` on the repo,
# writes a draft post to nox-hq.dev/src/content/blog/, then strikes
# the line through (or comments it out) on commit.
#
# Format: <github-org>/<repo>@<ref>   <- ref optional, defaults to HEAD
#
# Categories: agent frameworks, LLM SDKs, RAG, MCP servers, vector
# DBs, AI dev tools. Curated for AI-security relevance — skipping
# repos that are purely tutorial / dataset / model weights.
#
# Refill via PR when this list runs short.
